# Light_Analysis_Examples
Software examples for Thorlabs' products that are used to measure light like power meters (PM100A, PM100D, PM100D2, PM100D3, PM100USB, PM101, PM101A, PM101R, PM101U, PM102, PM102A, PM102U, PM103, PM103A, PM103U, PM103E, PM160, PM160T, PM160T-HP, PM16-120, PM16-121, PM16-122, PM16-130, PM16-140, PM16-144, PM16-401, PM16-405,PM16-425, PM200, PM400, PM5020, PM60A, PM60C, PM60CH, PM61A, PM61C, PM61CH), beam profilers (BC207VIS, BC210CV, BC210CU), wavefront sensors (WFS31-5C, WFS31-7AR, WFS31-14AR, WFS31-K1, WFS31-K2, WFS40-5C, WFS40-7AR, WFS40-14AR, WFS20-5C, WFS20-7AR, WFS20-14AR, WFS20-K1, WFS20-K2), polarimeters (PAX1000VIS, PAX1000IR1, PAX1000IR2), spectrometers (CCT10,  CCT11, CCT12, CCT14, CCS100, CCS175, CCS200, OSA201C, OSA202C, OSA205C, OSA207C), wavemeters (WM201, WM202, WM203), extinction ratio meter (ERM200) and intensity noise analyzer (PNA1) 

## Repo Organization
All examples are split up by programming language and product type. Directions on using specific examples are given within the folders.

### C# and C++ Soft Requirements

Guides written for these examples are written with Microsoft's Visual Studio in mind, which can be downloaded [here](https://visualstudio.microsoft.com/).
Other IDEs can be used, but instructions are not provided in this repository.
