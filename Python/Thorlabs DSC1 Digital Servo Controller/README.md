## Included Examples

### Thorlabs DSC1_example.py
This sample code demonstrates how to connect to a DSC1 dual-channel spectrometer, acquire spectral data, and display the measured spectra.

It is based on the Python wrapper `dscx_sdk.py`, which is installed in the following directory:

C:\Program Files (x86)\Thorlabs\DSCXClient\sdk\python

Depending on the installation location, the `dllpath` variable may need to be adjusted accordingly.

The Matplotlib package must be installed on the computer to display the spectra.
