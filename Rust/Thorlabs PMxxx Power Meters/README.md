## Included Example

### Thorlabs PMxxx Power Meters
In this folder you can find sample code showing how to control a Thorlabs PMxxx power meter from Rust.

There is one sub folder:

- **Linux USBTMC:** Code example using text-based [SCPI](https://en.wikipedia.org/wiki/Standard_Commands_for_Programmable_Instruments) commands over the Linux kernel USBTMC driver (`/dev/usbtmc*`), without NI-VISA or the Thorlabs TLPMx driver. For closer info read [Readme](Linux%20USBTMC).
